### Step 1.5: Create Firebase Project & Firestore Database

- **Status**: ⏳ Pending (Manual Step Required)
- **Objective**: Set up Firebase project in Google Cloud Console and create Firestore database
- **Steps to Follow**:
  1. Go to [Firebase Console](https://console.firebase.google.com/)
  2. Click "Add project" or "Create a project"
  3. Enter project name: `fitness-app`
  4. Accept terms and create project
  5. Wait for project to be created (2-3 minutes)
  6. In Project Settings → General, copy credentials:
     - API Key
     - Auth Domain
     - Project ID
     - Storage Bucket
     - Messaging Sender ID
     - App ID
  7. Go to "Firestore Database" section
  8. Click "Create database"
  9. Select "Start in production mode"
  10. Select region closest to you (e.g., `us-central1`)
  11. Create database
  12. Go to Rules tab and update with Firestore Security Rules (see below)

**Firestore Security Rules** (in Step 1.5 implementation):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users collection - can only access own document
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }

    // Exercises subcollection - user can only access their own
    match /users/{userId}/exercises/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }

    // Workouts subcollection
    match /users/{userId}/workouts/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }

    // Meals subcollection
    match /users/{userId}/meals/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }

    // Meal Logs subcollection
    match /users/{userId}/mealLogs/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }

    // Photos subcollection
    match /users/{userId}/photos/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }

    // Goals subcollection
    match /users/{userId}/goals/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }
  }
}
```

- **Files to Update After Creation**:
  - `.env.local` (create from `.env.example` with real Firebase credentials)
- **Expected Outcome**: Firebase project created, Firestore database running, security rules deployed
- **Verification**:
  - ✅ Firebase project visible in console
  - ✅ Firestore database showing "Active"
  - ✅ Security rules deployed successfully
- **Next**: Copy credentials to `.env.local` and proceed to Step 2

### Step 2: Set up Firebase Configuration

- **Status**: ⏳ Pending (After Step 1.5 Complete)
- **Objective**: Configure environment variables with Firebase credentials and verify connection
- **Prerequisites**: Step 1.5 must be complete with Firebase project created
- **Files to Create/Update**:
  - `.env.local` - Firebase credentials from Firebase Console
- **Dependencies**: `firebase` (already in package.json)
- **Steps**:
  1. Copy `.env.example` to `.env.local`
  2. Fill in all Firebase credentials from Firebase Console:
     ```
     NEXT_PUBLIC_FIREBASE_API_KEY=your_actual_api_key
     NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
     NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
     NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
     NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
     NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
     ```
  3. Test connection by running dev server: `npm run dev`
  4. Check browser console for Firebase initialization messages
- **Expected Outcome**: Firebase SDK initializes without errors, ready for authentication setup
- **Verification**:
  - ✅ No Firebase initialization errors in browser console
  - ✅ `src/lib/firebase.ts` exports auth, db, storage successfully
- **Note**: Do NOT commit `.env.local` - it contains secrets
